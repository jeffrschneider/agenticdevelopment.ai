One agent can hold several stages by reading the same package at different moments. The deployment manager holds four.

Package and Release are the on-ramp: the easy way onto the mesh. Deploy is where the agent goes live.

Every other stage names its role, so you can build to it.

Put your own agent in the role, contract one, or have a person hold it. Retract and Rollback name their roles; the reference publisher and deployment-manager agents don't hold them.
