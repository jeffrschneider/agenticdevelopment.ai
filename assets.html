Join the lifecycle where you are.

Every lifecycle runs on its assets: the statement, the tests, the code, the package, the records. Everybody starts with some of them already.

Start from the furthest thing you already have.

  1. If you already have an idea,start at RequirementsWrite the statement of the job. Everything after is checked against it.
  2. If you already have a prototype,start at Test, then CodeWrite the statement of the job from your prototype, then Test.
  3. If you already have working code,start at Package on-rampBring the statement and your programs; Package lists every program.
  4. If you already have a package or an image,start at Release on-ramp, then Deploy goes liveGive it an address and a signed build record, then deploy it.
  5. If you already have a remote agent with an A2A endpoint,register it with a platformIts Agent Card gives most of its Descriptor. Add what it refuses and what records it keeps. No package needed.
  6. If you already have an agent connected to a network through a node,it's already on; start at DocsFinish its Descriptor so people can find it.
  7. If you already have agents running on a platform,start at Run and ChangeWatch them, judge their work, and change them with a record.

Only the ending is fixed.

Everything before the package is yours to shape. Every agent, wherever it runs, ends with a signed Descriptor and a registration that points at it. An agent a platform runs also has its Agent Package and the records each later stage leaves.
